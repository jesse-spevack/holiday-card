# holiday-card

Collects names and addresses for our holiday cards at `hi.verynormal.dev`.
Each family that signs up joins a pixel-art winter holiday party in our living room.

- How to work on it (code map, commands, preview, deploy, data rules): `AGENTS.md`
- What guests see, and the hidden extras: `docs/scope.md`
- The form flow, its copy, and the API contract: `docs/form.md`
- The contact Sheet and its Apps Script: `apps-script/README.md`

```sh
pnpm install
pnpm test
pnpm preview      # check a branch at its own URL
pnpm run deploy   # main only
```
